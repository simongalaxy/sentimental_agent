# Amazon Product Review - Sentimental Analysis using Hugging Face and Ollama LLM

===

A fully automated reviews analysis pipeline powered by models from Hugging Face and Ollama that can load and clean amazon product review data, remove duplicates and consolidate reviews with similar semantic meaning, obtain sentiments and categories from the review texts and then label the categories to the review record, and finally generate summaries and insights by products and by platforms in markdown format.

## Motivation

Categorizing, consolidating and analyzing large volumes of customer reviews in a structured manner would be very time-consuming, difficult and subjective by human. Although we can use LLM to do so but it is still time and token consuming but the output generated by LLM is not predictable.

---

## How this project could solve that problems?

Having consider the volumes of reviews where some of them were duplicated or semantically similar, solely using LLM to process all the reviews is not a viable solution. Hence, the technologies were used for enhancing the speed, accuracy and save-tokens:

1. **Hugging Face model for *Review Data Preprocessing*:
- deduplicate and consolidate reviews with similar/same semantic meanings.
- get sentiments from review texts. 
- get the catgories by product and platform and then label the categeory by its review text. **Fully Automate Categorization

2. **Ollama Large Language Model for *Generating summaries and insights* :
- obtain insights for each preprocessed dataframes by product and platform.
- generate positive and negative summaries from its reviews.

3. **Pandas for *Producing statistics and graphs*:

---

## How the *pipeline* works ?

1. **Process Data - load csv file, clean data and generate a list of dataframe by products and by platforms using **Pandas
2. **Deduplication and Consolidation - deduplicate and consolidate reviews with similar/same reviews using **SentenceTransformer, Paraphrase_mining and Pandas
3. **Sentimentation - obtain sentiment from review using **Transformer Pipeline
5. **Categorization and Labelling - obtain categories from reviews and then label the reviews by categories using **"Text Generation" and "zero-shot-classification" in Hugging Face Transformer.
6. **Statistics and Charts Generation - generate statistics and charts using **Pandas
7. **Insight Generation and Summarization - generate insights and summaries for positive and negative reviews using **Ollama LLM.

Though the above pipeline, the review data could be preprocessed much faster and more accurate using Hugging Face. The tokens saved could be fully utilized for generating insights and summaries of positive and negative reviews.
